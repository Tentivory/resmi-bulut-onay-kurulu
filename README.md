# RESMİ BULUT ŞEKLİ ONAY VE TESCİL KURULU

**Kuruluş Yılı:** 29 Ekim 1923 (gökyüzü henüz resmiyet kazanmamıştı)
**Merkez:** Bulutların Üstü, 7. Kat, Asansör Çalışmıyor
**Mühür:** Kırmızı mürekkepli, ıslanınca dağılan

---

Bu yazılım, gökyüzündeki herhangi bir bulutu **resmi evrak** haline getirir.

Koyun mu gördünüz? Ejderha mı sandınız? Kaynananızın profili mi çıktı?
Fark etmez. Kurul bakar, kurul onaylar, kurul damgalar.

## Kurulum

```bash
python3 onayla.py
```

Başka bir şey gerekmez. Çayınızı demleyin. Kurul bekler.

## Kullanım

Program sizden bulutun şeklini sorar.
Siz ne derseniz deyin, kurul **kabul eder**.
Çünkü kurulun işi reddetmek değil, evrak üretmektir.

Örnek:

```
Bulutun şeklini tarif edin: evin kirasını ödeyen bir martı
```

Çıktı tamamen resmi, tamamen ciddi, tamamen saçmadır.
